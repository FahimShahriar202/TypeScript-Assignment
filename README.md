# TypeScript Assignment

## Overview

This repository contains my TypeScript assignment solutions and two technical blog posts based on TypeScript concepts.

In this assignment, I have covered different TypeScript topics like: functions, union types, readonly tuples, generics, interfaces, array operations, OOP and asynchronous programming using Promises.

## Assignment Solutions

The "solutions.ts" file contains solutions to 8 TypeScript problems. These problems cover:

1) Functions with default parameters.
2) Union types and type narrowing.
3) Readonly tuples.
4) Generic functions and rest parameters.
5) Interfaces and array filtering.
6) Generics with `keyof` and indexed access types.
7) Classes, inheritance and access modifiers.
8) Asynchronous functions using Promises.
